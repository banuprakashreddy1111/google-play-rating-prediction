# Google Play Store App Rating Prediction

## 📌 Objective
Build a Machine Learning model to predict Google Play Store app ratings based on app characteristics and user engagement metrics.

## 🧩 Problem Statement
The Google Play Store is introducing a feature that boosts the visibility of promising apps by giving them higher priority in recommendations (such as *Similar apps*, *You might also like*, and *New and updated games*) and improved search rankings.  
This project analyzes how app features influence ratings and helps identify high-potential apps early, improving app discoverability and developer opportunities.

## 📊 Dataset
Google Play Store dataset containing:
- App Category
- Reviews
- Size
- Installs
- Price
- Content Rating
- Genres
- Current App Rating

## ⚙️ Approach
1. Data cleaning and preprocessing
2. Handling missing values and outliers
3. Feature encoding and scaling
4. Exploratory Data Analysis (EDA)
5. Model building and evaluation
